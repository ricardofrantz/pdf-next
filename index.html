pdf-next

A small PDF, image and markdown viewer that reloads the moment the file changes. This page is its apt repository.

Install

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://ricardofrantz.github.io/pdf-next/pdf-next.asc \
  | sudo tee /etc/apt/keyrings/pdf-next.asc > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/pdf-next.asc] https://ricardofrantz.github.io/pdf-next stable main" \
  | sudo tee /etc/apt/sources.list.d/pdf-next.list > /dev/null
sudo apt update
sudo apt install pdf-next

Updates then arrive with apt upgrade like anything else. Only amd64 is published.

Remove

sudo apt remove pdf-next
sudo rm /etc/apt/sources.list.d/pdf-next.list /etc/apt/keyrings/pdf-next.asc
